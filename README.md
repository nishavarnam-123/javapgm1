# Multiply Two Numbers

This project multiplies two numbers entered by the user and prints the result.

## How to run

1. Open a terminal in the project folder.
2. Run the program:

```bash
python main.py
```

## Example

```text
Enter the first number: 5
Enter the second number: 4
The product of 5.0 and 4.0 is: 20.0
```

## Notes

- The program accepts numeric input only.
- If a user enters non-numeric values, it shows a friendly error message.
- The code is kept simple and beginner-friendly so it is easy to understand.
